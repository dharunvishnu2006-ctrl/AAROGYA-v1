## 🎯 What Problem Does This Solve?
India ABDM is digitizing health records for 1.4 billion people.
Apollo, AIIMS, Fortis need exactly this kind of analytics dashboard.
AAROGYA v1 makes patient health data visual, actionable and accessible.

---

## ✨ Features
| Feature | Description |
|---------|-------------|
| 📊 Health Dashboard | BMI, BP, Sugar interactive charts |
| 👥 Patient Records | Filter by city & gender |
| 🏥 Hospital Tracker | Real-time occupancy — Apollo, AIIMS, Fortis |
| 🔍 Risk Lookup | Low / Medium / High patient risk score |
| 📁 CSV Upload | Upload your own patient data |
| ✅ Tested | 5 pytest tests — all passing! |

## ⚙️ How to Run Locally
```bash
# Clone the repo
git clone https://github.com/dharunvishnu2006-ctrl/AAROGYA-v1.git
cd aarogya-v1

# Create virtual environment
virtualenv venv
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```
