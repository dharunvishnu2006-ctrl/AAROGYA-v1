- BMI, BP, Sugar dashboard show pannum
- Patient risk — Low/Medium/High calculate pannum

## 🛠️ Tech Stack
- Python + Pandas + Matplotlib
- Streamlit + pytest

## ⚙️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
